# Superstore-Sales-Dashboard-Power-BI-

🔍 Overview

The dashboard provides a 360° view of store performance, combining KPI cards, trend charts, geographic breakdowns, and category-level analysis into two report pages:


Page 1 — Sales Overview: KPIs, monthly sales & profit trends, category/sub-category breakdown, segment & payment mode mix, regional map, and a region slicer for interactive filtering.
Page 2 — Forecast: 15-day sales forecast and state-level sales breakdown.
